# v1.0 result files

Generated by [`../run_v1.py`](../run_v1.py). Do not edit by hand.

## `v1_paired_17_19.csv` and `v1_paired_-13_-7.csv`

One row per arm per trial:

| Column | Meaning |
|---|---|
| `trial` | Trial index, 0-based |
| `seed` | Seed used for both arms of the pair |
| `target_c`, `target_d` | Target pair |
| `arm` | `control` or `select` |
| `iterations` | Hitting time $T$ |
| `final_x`, `final_y` | Auxiliary pair at the end of the trial (`1,1` in the control arm) |

Each file has 10,000 pairs (20,000 rows): one control row and one select
row per pair.

## `v1_summary.json`

Aggregates: trials, mismatches, mean, SD, min, max, theoretical mean and SD,
runtime, and the CSV path for each target.

## `SHA256SUMS`

SHA-256 checksums of the result files. The experiment is deterministic; if
the checksums differ after a rerun, something in the code or the environment
changed.
